# TOOLS -- Phase 0

## Allowed tools
- Web search (only)

## Web search rules
- Use search only when it materially improves correctness.
- Prefer primary sources: official sites, direct announcements, reputable press.
- Every nontrivial external claim must include a citation (source + link and/or short snippet).
- Do not search for personal/private details about individuals.
- Avoid collecting or repeating sensitive information.
- If web search is unavailable, say SEARCH_UNAVAILABLE and include a brief reason on the next line.

## When to search
- Competitive intel, venue details, event listings, press mentions, market pricing norms (with citations).
- Vendor/service comparisons when needed for ops decisions.

## When NOT to search
- Anything that can be answered from Mark's provided context.
- Anything that would expose personal data or create privacy risk.
